# 重复检查与连续审核

重复检查生成候选与证据报告。审核保存隔离意图，执行清单确认之后才移动文件。

## 检查范围

- **日常检查**：读取实际图片和附属文件清单，结合整包大小与 SHA-256、清单 CRC/大小、来源身份、标题/作者、旧抽样与封面线索发现候选。自动逐页验证强候选，弱线索保留为待验证。
- **完整内容检查**：逐页检查所有存在的已入库作品，绕过候选筛选，仍可复用有效缓存。
- **重新计算**：独立控制缓存。可与上述任一范围组合。
- **深入验证本组**：生成新的报告，仅重查选中组，保留其他组及其证据引用。
- 单组验证在原队列位置更新结果，并保留当前组和页码；组拆分时定位到对应成员的新组，候选消失时定位到邻近候选。

未入库项目显示计数；在主窗口扫描入库之后才能参与现有数据库合并。默认每个读取阶段并发两本。

## 判定与证据

图片 SHA-256 分别汇总为阅读顺序签名和保留重复页数量的多重集合签名；附属文件按路径、大小与 SHA-256 比较。重新编码的相似画面仍需人工看图。

来源保留数据库原始 URL、有效元数据 URL 和 `.ehviewer`，统一为带 provider 的身份。EH/EX 共用命名空间，nHentai 独立。缺失、无效、多个标记和来源冲突均可见。

候选组是审阅集合，其中独立的内容等价子组才提供隔离建议。A/B 内容相同、C 为另一版本时，可以保留 A/C，将 B 明确映射到 A。

仅因同系列、不同话或不同杂志期数产生的关联不再进入重复队列。作品标题键保留章话和作品卷数，并统一 Ch.01 / 第1話 / 第1话；未标编号不能充当任意编号的通配符。整期杂志按刊名与完整期号或年月匹配，同一期的彩色版、普通版等仍是人工版本候选。

标题中的刊载括号先拆出，例如《君は輝く月花のように (コミックメガストア Vol.13)》的作品话数未标注，Vol.13 属于刊载来源。《作品 第3話 (コミックメガストア Vol.16)》的作品话数是3，刊载期号是16。不能识别的括号原文保留，内部数字不提供作品卷话。界面分别显示作品卷话、刊载来源/杂志期号和版本。来源、文件与真实页面重复证据始终独立于标题编号。

批量建议要求文件可完整读取、没有未覆盖子内容、没有数据库路径重叠，且满足整包字节相同或完整内容与所有来源身份一致。相同页但附属资料不同、页面重排、不同版本和覆盖关系需要人工理由与差异确认。

文件夹页序沿用阅读器的直接子图片规则；递归清点随目录移动的所有文件。已入库子作品不能随着父目录隔离而留下失效记录，应分别审阅。文件夹每轮重新枚举子文件指纹，执行前仍重新读取内容证明。

## 审核与执行

界面提供概览、页面对照、附属文件差异、原始来源和技术证据。页面可按序号或相同 SHA 对齐，展示独有页与双方覆盖比例。预览在后台仅读取选中页与邻页，按窗口隔离并取消旧请求。

概览展示本组全部成员，按可用宽度和成员数量排成一至三列：两本在宽窗中各占一半，不预留第三列；窄窗自动改为单列。作者、语言、来源链接、完整路径和文件范围等资料直接显示。每张卡片直接勾选“保留这本”，取消勾选显示“拟隔离”；文件名和目录摘要帮助区分标题、封面相同的副本。未审核组默认全部保留，已保存审核恢复原有选择。同内容子组只剩一个保留项时自动生成归并关系，多个保留目标或跨版本归并需在卡片上明确选择；跨版本仍需理由和差异确认。“仅保留此副本”仅作用于已验证的同内容子组，其他版本继续保留。

勾选属于草稿，确认保存后才计入执行清单。同窗口切组保留草稿，证据变化时重置失效选择；有未保存草稿时不能执行，可从队列标记和底部提示返回继续审核。对照基准与保留选择相互独立，可从卡片进入页面对照。概览不读取逐页证据，页面和附属文件对照才按需调用现有异步通道。

审核结论包括确认重复、保留不同版本、不是重复、稍后处理。保存成功后可自动进入下一待审组。跨轮复用绑定成员、内容、来源和元数据指纹；证据变化重新要求审核，否定结论不会永久隐藏新候选。

执行清单列出唯一文件、原路径、目标路径、对应保留项、资料差异及状态合并影响。“拟移出库体积”表示移出 Library 的文件体积，同盘隔离不会释放磁盘空间。

执行前重新核验选中项的整包或逐页 SHA 证明、当前路径与来源元数据。保留现有备份、文件移动验证、数据库事务和失败回滚；收藏夹引用替换到对应保留项，阅读次数取最大值，收藏取并集，全部隐藏时才隐藏。

隔离历史提供原路径、隔离位置和备份入口，并保存关联记录的执行前后快照。成功隔离后的完整恢复仍是原方案中的独立后续里程碑；当前提供失败回滚和历史定位。

旧报告只读，重新检查后才能按新的证据契约审批。新报告使用 dedupeRulesVersion=2，规则版本参与 evidenceRevision；以前的系列候选报告需重新运行日常或完整检查，不能仅通过单组验证清理整库旧规则。内容清单和 SHA 缓存继续复用，不必勾选重新计算。原库数据库结构保持现有 Manga/Metadata 模型，新增审核与证据数据存储在 audit 目录。

## 验证

自动测试覆盖缺失旧指纹、重打包和改名、身份来源、重复/重排/插入/缺失页面、合集覆盖、多版本子组、目录子内容、缓存、审核跨轮复用、映射、陈旧证据、流关闭、取消、执行与回滚。

浏览器检查 1920×1080、1320×860、1024×768、760×600 的布局，覆盖2/3/5/20本全组展示、勾选归并、草稿切组恢复、保存失败不跳组、跨页导航、版本保留、清单和重开状态。真实 Electron 通道使用独立临时测试库从界面勾选并保存审核，验证100%/125%/150%缩放、预览、详情、定位、来源链接、隔离合并、历史与取消。

NAS 只读小样本：16,827,663 字节 ZIP，28 页。按清单→整包 SHA→逐页 SHA→选页预览顺序测量，分别约 26/70/105/84 ms；清单读取 6 次、887,641 字节，逐页读取 299 次、24,214,182 字节，两页预览正常，源大小与修改时间保持一致。这是单一样本与当前系统缓存条件下的观测值。
